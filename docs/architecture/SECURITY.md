# SECURITY

M1 is a synthetic fixture tool, not a sandbox for hostile sites. CLI starts its own exact numeric loopback origin. Policy requires explicit document route and button scope, refuses forms, downloads and new contexts. Browser intercepts requests, forbids non-GET, rejects redirects before delivery, disables service workers and WebSockets, and excludes subframes. Never pass real application traffic or secrets through this release. See [safety policy](../business/SAFETY_POLICIES.md).

# Milestone acceptance gates

| ID | Evidence required before requesting acceptance |
|---|---|
| M0 | Editable install, CLI smoke, fixture runnable, tests executable, linked docs and next tasks, no secrets |
| M1 | Expected fixture states/transitions, bounded loops, blocked financial and form actions, screenshot-backed offline reports |
| M2 | Objective-specific ordering, invalid recommendation rejection, recoverable provider failures, measured budget |
| M3 | Interrupted run recovery, preserved evidence, no duplicate completed actions, manual journey |
| M4 | Evidence-backed journey/feature/rule reports and usable offline output |
| M5 | Authorized X-Game authentication, catalog, profile/history, matchmaking, results and reproducible journeys |
| M6 | Permitted competitor exploration plus a comparative matrix and evidence-backed recommendations |
| M7 | Authorized Android fixture with matching report contracts |
| M8 | Repeatable Pong/Morris/Sky Flap test journeys and result verification |
| M9 | Historic baseline comparison and approved journey replay, optional CI integration |

Current statuses live in [PROJECT_STATUS](../../PROJECT_STATUS.md). Acceptance always requires explicit user approval.

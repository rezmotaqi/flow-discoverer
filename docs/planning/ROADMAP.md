# Roadmap

| Horizon | Milestone | Depends on | Value / release gate |
|---|---|---|---|
| Now | M0 foundation | — | Testable packaging, compact project memory and synthetic fixture |

| Next | M2 AI assistance | M1 | Bounded OmniRouter suggestions validated by deterministic policy |
| Next | M3 recovery and assisted recording | M1 | Durable frontier, checkpoints, protected sessions and manual recording |
| Next | M4 documentation | M1, M2 | Evidence-grounded journeys, classifications, coverage and offline reports |
| Later | M5 authorized X-Game QA | M3, M4, explicit permission | Reproducible internal target findings and acceptance |
| Later | M6 competitor benchmarking | M4, M5, external permission | Offline matrices and evidence-backed recommendations |
| Deferred | M7 Android | browser foundation validated | Authorized Android fixture and equivalent reports |
| Deferred | M8 gameplay | M1, isolated test games | Pong, Nine Men's Morris and Sky Flap adapters |
| Deferred | M9 continuous QA | M3, M4 | Historical diff, approved journey replay and optional CI schedules |

Out of scope: unauthorized automation, real transactions, data collection from private accounts, and external ranked play. No external monitoring enabled by default.
